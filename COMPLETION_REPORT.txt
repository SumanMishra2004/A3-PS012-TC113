KEY FEATURES
================================================================================

Classification System:
  • RECURSIVE: RA flag + expected answer (nonce defeats caching)
  • AUTHORITATIVE_ONLY: AA flag + RA=0
  • REFUSED: RCODE=REFUSED
  • INCONCLUSIVE: With reason codes (TIMEOUT, SERVFAIL, RA_SET_NO_ANSWER, etc.)

Reproducibility:
  • Deterministic target ordering (sorted by IP)
  • Seeded nonce generation (sha256-based)
  • Seeded jitter in backoff
  • --seed flag for exact reproduction
  • --repeat N for consistency analysis

Rate Limiting:
  • Token bucket algorithm (per-server + global)
  • Mandatory (cannot be disabled)
  • Global budget tracking
  • Hard caps enforced at validation time

Testing:
  • 27 unit tests covering all modules
  • Table-driven classification tests
  • Guard rail validation tests
  • Test framework ready for integration tests

Security & Ethics:
  • Authorized use enforcement
  • Public IP warning with --allow-public flag
  • Responsible disclosure workflow
  • No Internet-wide scanning capability
  • Rate control prevents abuse

CLI COMMANDS
================================================================================

dnsprobe validate-config
  Validates targets.yaml and settings.yaml, enforces hard constraints

dnsprobe scan --targets CONFIG --settings CONFIG --seed 42 --repeat 3 --out DIR
  Executes DNS probes with reproducibility, saves results

dnsprobe evaluate --results RESULTS --targets CONFIG
  Compares against ground truth, computes metrics (accuracy, precision, recall)

dnsprobe report --results RESULTS --format html,md,json,csv
  Generates reports in multiple formats

DOCKER LAB NETWORK
================================================================================

Network: 10.10.0.0/24 (fixed, non-routable lab-only)

Servers & Their Classification:
  10.10.0.101  bind-open           → RECURSIVE (test case)
  10.10.0.102  bind-acl-refused    → REFUSED (test case)
  10.10.0.103  bind-auth-only      → AUTHORITATIVE_ONLY (test case)
  10.10.0.104  unbound-open        → RECURSIVE (test case)
  10.10.0.105  unbound-refuse      → REFUSED (test case)
  10.10.0.106  blackhole           → INCONCLUSIVE: TIMEOUT
  10.10.0.107  flaky               → INCONCLUSIVE: CONTRADICTORY
  10.10.0.108  ra-misleading       → INCONCLUSIVE: RA_SET_NO_ANSWER
  10.10.0.200  upstream-auth       → AUTHORITATIVE_ONLY (ext.lab)
  10.10.0.50   client              → Probe vantage point

Three-Probe Strategy:
  Probe A: www.lab.test A RD=1              (Authoritative check)
  Probe B: <nonce>.probe.ext.lab A RD=1     (Recursion check)
  Probe C: <nonce>.probe.ext.lab A RD=0     (Control, no recursion)

Each probe captures: RCODE, flags (AA, RA, TC), answer section, latency, errors
